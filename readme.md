# Employee Management CRUD

A simple Employee Management System built using Node.js, Express.js, EJS and MySQL.

This project demonstrates CRUD operations using a MySQL database.

## Features

- Add new employee
- View all employees
- View employee details
- Edit employee details
- Delete employee
- MySQL database integration
- EJS templates
- Express.js routing

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- EJS
- MySQL

## Employee Details

The application manages the following employee information:

- ID
- Name
- Email
- Department
- Salary

## CRUD Operations

### Create

Add a new employee to the MySQL database.

### Read

View all employees and individual employee details.

### Update

Edit existing employee information.

### Delete

Delete an employee from the database.
